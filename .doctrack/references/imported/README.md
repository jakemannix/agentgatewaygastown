# README.md (imported)

Source: `README.md`

Agentgateway is the **first complete** connectivity solution for Agentic AI. Open source data plane optimized for agentic AI connectivity within or across any agent framework or environment.

## Key Features
- **Highly performant** — written in Rust, designed for any scale
- **Security First** — robust MCP/A2A focused RBAC system
- **Multi Tenant** — multiple tenants with own resources and users
- **Dynamic** — dynamic configuration updates via xDS, no downtime
- **Run Anywhere** — single machine to large-scale multi-tenant deployment
- **Legacy API Support** — transform legacy APIs into MCP resources (OpenAPI supported, gRPC coming)

## Deployment Modes
- **Standalone**: [agentgateway.dev/docs](https://agentgateway.dev/docs/)
- **Kubernetes**: [kgateway.dev/docs/agentgateway](https://kgateway.dev/docs/agentgateway/) — agentgateway as data plane for kgateway (Kubernetes Gateway API control plane)
